BISS Studio V2.9.0 — CURRENT INSTALLATION NOTES

The filename is retained for compatibility with older backup packages.
For a full recovery, use docs/RECOVERY_RUNBOOK.md.

1. Clone https://github.com/2jcjpyw7vh-bot/biss-studio and use branch main.
2. Run: pnpm install --frozen-lockfile
3. Run: pnpm test
4. Apply the SQL files in the exact order documented in docs/RECOVERY_RUNBOOK.md.
5. Configure these Studio-only Vercel environment variable names:
   NEXT_PUBLIC_STUDIO_SUPABASE_URL
   NEXT_PUBLIC_STUDIO_SUPABASE_PUBLISHABLE_KEY
   STUDIO_SUPABASE_SECRET_KEY
   NEXT_PUBLIC_SITE_URL
   ADMIN_PIN                  (legacy/bootstrap fallback only)

Optional integrations:
   YOUTUBE_API_KEY
   GEMINI_API_KEY
   GEMINI_MODEL
   ARBOX_API_V3_BASE_URL
   ARBOX_API_KEY

Old NEXT_PUBLIC_SUPABASE_* and SUPABASE_SECRET_KEY names remain code fallbacks only.
Do not point them to the shared legacy project. Never copy values from BISS Vineyard.

No secret value belongs in this file, GitHub, screenshots, chat, or backup manifests.
