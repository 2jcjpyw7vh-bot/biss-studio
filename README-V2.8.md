# BISS Studio V2.8.1 — Dynamic Equipment Intelligence

גרסת עדכון מלאה שמבטלת את הצורך לערוך קוד ידנית בכל פעם שנוסף ציוד לסטודיו.

## מה חדש

### 1. ציוד חדש → תרגילים חדשים אוטומטית
כאשר מנהל מוסיף ציוד עם ה-PIN:
- הציוד נשמר ב-Supabase.
- המערכת מונעת כפילויות.
- נוצרות אוטומטית הצעות תרגילים מתאימות.
- לכל תרגיל נשמרים עברית/אנגלית, אזור, שרירים, רמה, cue, progression, regression ובטיחות.
- YouTube API מחפש ושומר סרטון הדרכה מתאים.
- התרגילים מופיעים מיד בספרייה, במסננים ובמחולל האימונים.

לציוד המוכר של הסטודיו (בר ונקודות העיגון) קיימת גם ספרייה מובנית, כך שהוא עובד גם ללא Gemini.

### 2. ציוד חדש לא דורש שינוי במסננים
רשימות אזור/ציוד נבנות בזמן אמת מספריית התרגילים וממלאי Supabase.

### 3. Super Fit / סופר-סט שרירים מנוגדים
נוסף מבנה אימון:
`סופר סט / Super Fit`

המנוע מנסה לצמד באופן אוטומטי:
- חזה ↔ גב
- יד קדמית ↔ יד אחורית
- ארבע-ראשי ↔ ירך אחורית
- ליבה קדמית ↔ שרשרת אחורית

### 4. ספרייה מורחבת
המיגרציה מוסיפה 30 תרגילים חדשים/מתקדמים, כולל:
- בר קבוע
- נקודות עיגון רצפה וגובה מותן
- Renegade Row
- Bulgarian Split Squat
- Single-leg RDL
- Dumbbell Thruster
- Kettlebell Swing
- Clean & Press
- Physio Ball Pike
- BOSU Squat with Reach
- Face Pull ועוד.


### 6. בחירה מרובה — ציוד ואזורי גוף
בכל מסכי הבחירה המרכזיים ניתן לבחור יותר מאפשרות אחת בו-זמנית:
- בניית אימון: כמה אזורי גוף וכמה סוגי ציוד.
- ספריית תרגילים: סינון לפי כמה אזורים וכמה מכשירים.
- שיעורי בית: כמה אזורים וכמה סוגי ציוד.
- תוכנית רב-שבועית: כמה אזורים וכמה סוגי ציוד.

בחירה ריקה/“הכל” פירושה ללא סינון. הבחירות מוצגות ככפתורי בחירה ברורים ולא דורשות Ctrl/Shift.

### 5. דפי תרגיל דינמיים
תרגילים שנוצרים אחרי ההתקנה נפתחים בדף תרגיל מלא בדיוק כמו התרגילים המקוריים.

# התקנה — ללא עריכת שורות קוד

## א. העלאת הקבצים
העלה את תוכן ה-ZIP לריפו תוך שמירה על מבנה התיקיות ובחר Replace לקבצים הקיימים.

## ב. Supabase
פתח SQL Editor והריץ פעם אחת:
`supabase/v2.8-auto-exercises.sql`

## ג. Vercel Environment Variables
המשתנים הקיימים נשארים:
- NEXT_PUBLIC_SUPABASE_URL
- SUPABASE_SECRET_KEY
- ADMIN_PIN
- YOUTUBE_API_KEY
- NEXT_PUBLIC_SITE_URL

כדי שכל ציוד עתידי ולא מוכר יקבל תרגילים אוטומטית, הוסף פעם אחת:
- `GEMINI_API_KEY`

אופציונלי:
- `GEMINI_MODEL=gemini-2.5-flash`

אחרי הוספת משתנה סביבה יש לבצע Redeploy.

## ד. בדיקה
1. מצב מנהל → ציוד.
2. הוסף ציוד חדש.
3. לאחר השמירה תופיע הודעה כמה תרגילים נוצרו.
4. עבור לספריית תרגילים וסנן לפי שם הציוד.
5. בנה אימון ובחר `סופר סט / Super Fit` לבדיקה.

## הערת בטיחות
התוכן האוטומטי מיועד ככלי עבודה למדריכה. לפני שימוש בתרגיל חדש יש לוודא שהשימוש מתאים לציוד בפועל, שהוא תקין ומעוגן כראוי, ולהתאים עומס וטווח למתאמנת.
