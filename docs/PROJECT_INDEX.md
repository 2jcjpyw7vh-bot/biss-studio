# BISS Studio — מפת תיקיית הפרויקט

- `CONTINUITY.md` — מצב המערכת, סביבת הייצור והמשך הפיתוח.
- `app/` — מסכי המערכת ונתיבי השרת.
- `data/` — נתוני בסיס לתרגילים ולציוד.
- `lib/` — לוגיקה משותפת, משפחות ציוד וחיבורי שרת.
- `supabase/` — סכמות Studio המתועדות בקוד.
- `test/` — בדיקות אוטומטיות.
- `backups/` — גיבויים מקומיים מתוארכים; קובצי ZIP אינם מועלים ל-GitHub.
- `reports/` — דוחות בדיקה, UX ואבטחה שיופקו בהמשך.

אתר הייצור: https://biss-studio.vercel.app

אין להכניס לתיקייה זו קבצי BISS Vineyard או סודות גישה.
