BISS Studio V2.7 — התקנה

A. GitHub
1. פתח את שורש הריפו biss-studio.
2. Add file > Upload files.
3. גרור את התוכן שבתוך BISS-Studio-V2.7-Professional-UX:
   - app
   - data
   - supabase
   - README.md
   - הוראות-התקנה.txt
4. ודא שהנתיבים מתחילים ישירות ב-/app, /data, /supabase.
5. Commit directly to main.
6. המתן ב-Vercel ל-Ready.

B. Supabase — פעם אחת בלבד
1. פתח SQL Editor.
2. פתח את הקובץ supabase/v2.7-equipment-migration.sql.
3. העתק והריץ את כולו.
4. הקוד משתמש ב-WHERE NOT EXISTS ולכן לא אמורות להיווצר כפילויות.

הציוד החדש:
- בר קבוע בסטודיו: 1
- עיגון גומיות בגובה רצפה: 2
- עיגון גומיות בגובה מותן: 4

לא לשנות Secret Keys או Environment Variables.
