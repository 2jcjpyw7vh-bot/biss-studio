# BISS Studio V2.9.0

מערכת לבניית אימוני סטודיו, ניהול מלאי וקיבולת תחנות, רצף בין מדריכות, שיבוץ מחליפות ותוכניות אימון אישיות.

## נקודת כניסה למי שממשיך את הפרויקט

1. לפתוח את `SUCCESSOR_START_HERE.txt`.
2. לקרוא את `CONTINUITY.md` לקבלת תמונת מצב עדכנית.
3. לעבור על `docs/SUCCESSION_AND_ACCESS.md` לפני שינוי חשבונות או הרשאות.
4. במקרה של תקלה או הקמה מחדש, לפעול לפי `docs/RECOVERY_RUNBOOK.md`.

```text

pnpm test
pnpm dev
```

נבדק עם Node.js `24.22.1` ו-pnpm `11.25.0`.
