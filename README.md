# BISS Studio Workout · V2

מערכת אינטרנטית לצוות BISS: חיפוש תרגילים, יצירת אימונים, תוכניות, שיעורי בית, מלאי ושיתוף.

## מה כבר בפנים
- מיתוג BISS לפי הלוגו שסופק.
- ספריית תרגילים בעברית/אנגלית עם שרירים, ציוד, רמה, דגשים ורגרסיות.
- חיפוש לפי אזור/שריר/ציוד, כולל משקל גוף בלבד.
- בניית אימון: תחנות, סטים וחזרות, AMRAP, EMOM ופירמידה.
- התרעה לפי כמות ציוד כשצריך זוגות/רוטציה.
- שיעורי בית למתאמנת: חיזוק, יציבות, מוביליטי ושחרור.
- תוכנית רב-שבועית עם התקדמות שבועית בסיסית.
- Spotify: קישור לשיר/פלייליסט לאימון או לתרגיל.
- שיתוף ל-WhatsApp, מייל או העתקת קישור.
- דפי שיתוף נקיים וממותגים.
- ניהול ציוד: הוספה, שינוי כמות, סימון לא זמין ומחיקה.
- PIN נבדק בצד השרת בלבד.

## מלאי שדורש אישור
הקטלבלים הוזנו זמנית כהנחה של 4 יחידות מכל אחד מהמשקלים 4, 6 ו-8 ק״ג. יש לעדכן אם הכוונה הייתה אחרת.

## חיבור Supabase
1. צרו Project ב-Supabase.
2. ב-SQL Editor הריצו `supabase/schema.sql`.
3. הריצו פעם אחת את `supabase/seed.sql`.
4. העתיקו את Project URL ואת ה-Secret key לשימוש בצד השרת בלבד.

## משתני סביבה
העתיקו `.env.example` ל-`.env.local`:

```bash
NEXT_PUBLIC_SUPABASE_URL=...
SUPABASE_SECRET_KEY=...
ADMIN_PIN=106106
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

אין להעלות `.env.local` ל-GitHub. בפריסה ב-Vercel יש להכניס את הערכים ב-Environment Variables.

## הרצה מקומית
```bash
npm install
npm run dev
```

## פריסה ב-Vercel
1. מעלים את התיקייה ל-GitHub.
2. יוצרים Project חדש ב-Vercel מתוך ה-Repository.
3. מוסיפים את ארבעת משתני הסביבה.
4. Deploy.
5. לאחר קבלת הדומיין, מעדכנים `NEXT_PUBLIC_SITE_URL` לדומיין המלא ומבצעים Redeploy.

## בטיחות ושימוש מקצועי
גרסה זו היא כלי עבודה למדריכה. היא אינה מחליפה שיקול דעת מקצועי, אבחון רפואי או טיפול. תרגילי שחרור/מוביליטי מיועדים לעבודה כללית בלבד; במקרה של כאב משמעותי, נפיחות, חבלה, נימול/הקרנה, חולשה חדשה או מגבלה לא מוסברת יש להפנות לבדיקה מתאימה.

## השלב הבא אחרי פריסה
- חשבונות אישיים למדריכות במקום PIN משותף.
- ספריית סרטוני BISS מאושרים.
- מועדפים והיסטוריית אימונים.
- מנוע AI מחובר למלאי ולכללי הסטודיו.
- תוקף/ביטול לקישורי שיתוף.

## V2.1 — התאמות למגבלות

- אפשר לבקש חלופה אחרת.
- המנגנון אינו אבחון רפואי ואינו מחליף הנחיה רפואית.
